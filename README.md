# Springer Capital — Web Platform

This repository contains the web application platform for **Springer Capital**.

## 📁 Repository Structure

- [`frontend/`](./frontend/): Next.js 16 client application built with React 19, Tailwind CSS v4, Zod validation, and shadcn/ui components.
  - [Frontend Developer Guide & Architecture](./frontend/README.md)
  - [Architecture Specification](./frontend/ARCHITECTURE.md)

## 🚀 Quick Start (Frontend)

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3003](http://localhost:3003) to access the application.

For detailed documentation, architecture breakdown, and component guides, please refer to [frontend/README.md](./frontend/README.md).
